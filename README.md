# Proyecto de Pruebas Automáticas para la Creación de Kits

Este proyecto contiene pruebas automatizadas para verificar la funcionalidad de creación de kits dentro de un usuario en la API.

## 📂 Estructura del Proyecto
- `configuration.py` → Contiene la URL base y rutas de la API.
- `data.py` → Define los datos de prueba.
- `sender_stand_request.py` → Contiene funciones para interactuar con la API.
- `create_kit_name_kit_test.py` → Contiene las pruebas.
- `.gitignore` → Archivos a ignorar.
- `README.md` → Documentación del proyecto.
