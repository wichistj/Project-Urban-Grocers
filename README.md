# Proyecto de Pruebas Automáticas para la Creación de Kits

Este proyecto contiene pruebas automatizadas para verificar la funcionalidad de creación de kits dentro de un usuario en la API.

📂 Estructura del Proyecto
- `configuration.py` → Contiene la URL base y rutas de la API.
- `data.py` → Define los datos de prueba.
- `sender_stand_request.py` → Contiene funciones para interactuar con la API.
- `create_kit_name_kit_test.py` → Contiene las pruebas.
- `.gitignore` → Archivos a ignorar.
- `README.md` → Documentación del proyecto.

# Requisitos Previos

Antes de ejecutar las pruebas, asegúrate de tener instalado Python 3 y las librerías necesarias. 
Puedes instalarlas ejecutando el siguiente comando en la terminal:
_pip install -r requirements.txt_

pip install pytest requests

# Ejecución de las pruebas

Ejecución de las Pruebas

Para ejecutar todas las pruebas, usa el siguiente comando en la terminal dentro del directorio del proyecto:

pytest folder/del/proyecto

Esto ejecutará las pruebas y mostrará los resultados en la terminal.

También puedes ejecutar un archivo de prueba específico con:

Py test iniciando el banco del servidor en turno.
